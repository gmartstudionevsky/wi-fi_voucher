# Архитектура Wi-Fi voucher 2.0

## Production

Рабочий модуль больше не зависит от постоянно запущенного контейнера:

1. Cloudflare Pages раздаёт статический интерфейс из `dist/`.
2. Supabase Auth хранит пользовательские сессии и автоматически обновляет токены.
3. Интерфейс вызывает только RPC-функции `public.voucher_*` с JWT пользователя.
4. Таблицы с паролями остаются в закрытой схеме `wifi_voucher` и не доступны через Data API напрямую.
5. PDF собирается в браузере из подготовленных PDF-шаблонов. LibreOffice в production не требуется.

Render остаётся временным аварийным вариантом до завершения переключения, но не участвует в новом рабочем запросе.

## Авторизация

- Доступ назначается по паре `user_id + hotel_id` в `wifi_voucher.memberships`.
- Роли: `admin`, `operator`, `viewer`.
- Сотрудник получает доступ только при совпадении рабочей почты с приватным приглашением.
- Публикуемый ключ Supabase разрешено помещать во frontend; секретный/service-role ключ в браузер не передаётся.
- Каждая SECURITY DEFINER RPC-функция проверяет `auth.uid()`, активное членство, отель и требуемую роль.

## Атомарность

- Выдача выбранных паролей блокирует и переводит все строки в `used` в одной транзакции.
- Генерация PDF сначала резервирует пароли через `FOR UPDATE SKIP LOCKED`.
- После сборки файла клиент подтверждает резерв; только тогда пароли становятся использованными.
- При ошибке клиент освобождает резерв. Зависшие резервы автоматически освобождаются через 20 минут.
- Уникальное ограничение `(hotel_id, password)` остаётся последним уровнем защиты от дубликатов.

## Состав frontend

- `client/index.html` — разметка standalone-модуля и экран входа.
- `client/styles.css` — адаптивный интерфейс.
- `client/app.js` — сессия, RPC, таблица, импорт и устойчивость соединения.
- `client/pdf.js` — локальная сборка PDF и QR-кодов.
- `web/public/templates/` — очищенные PDF-шаблоны и координаты динамических областей.
- `supabase/migrations/` — воспроизводимая схема RPC, ролей, приглашений и аудита.

## Разработка и сборка

```powershell
pnpm install
pnpm run dev
pnpm run build
node scripts/verify_client_pdf.mjs
```

Cloudflare Pages:

- build command: `pnpm run build`;
- output directory: `dist`;
- production branch: `main`;
- Node.js: 24.

## Интеграция в общую панель отеля

Модуль уже разделяет интерфейс, Auth и контракт данных. При появлении общей панели она сможет:

- использовать ту же Supabase-сессию;
- открывать модуль отдельным маршрутом или microfrontend;
- выбирать отель по членству пользователя;
- вызывать тот же набор `voucher_*` RPC;
- использовать `module.id = wifi-voucher` и заявленные capabilities из `voucher_bootstrap()`.
