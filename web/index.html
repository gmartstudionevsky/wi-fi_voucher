Генератор брошюр с Wi‑Fi паролем

Гостевая страница

Укажите количество брошюр на русском и английском. Сервис зарезервирует нужное количество паролей через общий Apps Script endpoint, запишет выдачу в архив и сформирует один PDF для двусторонней печати.

Пароли больше не удаляются из листа Пароли. Выданные коды определяются по архиву запрошено через QR-код, поэтому гостевая выдача и генератор брошюр не забирают один и тот же ваучер.
